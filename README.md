# Axentra M-Pesa Automation

## Project Overview
A Make.com automation prototype designed to receive simulated M-Pesa transaction notifications through webhooks.

## Technologies
- Make.com
- Webhooks
- JSON
- ReqBin
- Google Sheets

## Implemented
- Created a Make.com workspace.
- Configured a custom webhook.
- Tested webhook reception using simulated M-Pesa notification data.
- Prepared a Google Sheets destination for transaction records.

## Planned Improvements
- Map incoming webhook data to Google Sheets.
- Automate transaction record creation.
- Add data validation and error handling.
- Explore payment notification monitoring.

## Project Status
Prototype – In Development.
